# Assets

Card sounds: Kenney, Casino Audio, CC0. Playback uses compact mono 44.1 kHz, 96 kbps MP3 files. Source WAVs remain preserved. Source: https://kenney.nl/assets/casino-audio. License included in audio/LICENSE-Kenney.txt.

Expression images: Microsoft Fluent Emoji, MIT, copyright Microsoft Corporation. Source commit 1ffb34c752ecf5d402f04cfb4b392c77f57c54bc of https://github.com/microsoft/fluentui-emoji. License included in expressions/LICENSE-Microsoft.txt. These are consistent 3D image assets, not redistributed Apple emoji font artwork.

Seal sticker: original PNG supplied by the user for this project, preserved without modification. The game uses a 256 px transparent WebP copy. Three additional expressions (tongue out, happy, crying) were generated with the built-in imagegen tool from the user's character references, then encoded as transparent WebP. Each sticker is 5–8 KB. Prompts and output paths are recorded in the project STICKER_NOTES.md.

Fluent Emoji playback copies use transparent 128 px WebP (2–3 KB each); original PNGs and their license remain preserved. Images load only when the picker opens or that specific expression is received. MP3 samples load when entering a table. All media requests use normal browser caching; messages carry only short expression identifiers, never image bytes.
